# 四指力控与键盘开合

默认控制右手食指、中指、无名指、小指，保持拇指两个目标为启动位置。两个脚本均默认只读预览，只有添加 `--execute` 才发送控制及退出复位请求；不要同时运行多个手部控制脚本。

先按[手部接口检查](../README.md#只读检查)启动桥并加载 ROS2 环境。力值单位、关节名称和硬件范围见 [hand 接口定义](../../../../src/hand/README.md)。

| 文件 | 职责 |
|---|---|
| `force_control.py` | 四指力误差调节、力反馈过滤和超力保护；默认参数集中在 `DEFAULTS` |
| `keyboard_four_fingers.py` | 按键开合和反馈显示 |
| `hand_common.py` | ROS2 订阅、请求校验、关节过滤、终端处理和退出复位 |

## 键盘开合

```bash
python3 native_bridge/tests/hand/force_control/keyboard_four_fingers.py
```

在交互式终端中使用；实际控制时添加 `--execute`。`--side` 默认 right；`--step` 默认 `0.05 rad`，允许 `(0, 0.1] rad`。

| 按键 | 动作 |
|---|---|
| `c` | 四指从当前反馈位置各闭合一小步 |
| `o` | 四指从当前反馈位置各打开一小步 |
| `p` | 只打印最近一次有效的六关节角度，rad |
| `f` | 打印全部原始力通道、换算后的 N 值及新鲜度 |
| `q` / Ctrl+C | 退出 |

每秒最多处理 5 次开合，等待服务响应或新关节反馈时不排队。指尖力仅供显示，不推定通道映射，不参与力控或超力保护。`f` 的 `force_status` 区分新鲜、过期、未收到和无效数据。

## 持续力控

先预览 10 秒：

```bash
python3 native_bridge/tests/hand/force_control/force_control.py \
  --pressure-indices 1 2 3 4 --duration 10
```

确认映射和参数后运行持续力控：

```bash
python3 native_bridge/tests/hand/force_control/force_control.py \
  --pressure-indices 1 2 3 4 --execute
```

`--pressure-indices` 必须按食指、中指、无名指、小指填写经确认的原始数组下标（从 0 开始）。上述 `1 2 3 4` 是示例；当前每手返回六个力值，不能从六关节顺序推定力通道映射。

| 参数 | 默认值 | 含义 |
|---|---|---|
| `--side` | right | 手侧，可选 left |
| `--targets` | 0.17 / 0.17 / 0.17 / 0.16 | 食指到小指的目标力，N |
| `--kp` | 0.1 | 每次更新的比例增益，rad/N |
| `--max-step` | 0.05 | 每次更新最大角度变化，rad |
| `--deadband` | 0.01 | 力误差死区，N |
| `--max-force` | 2 | 任一受控指的绝对力达到此值即退出，N |
| `--rate` | 5 | 最大更新频率，Hz，上限 20 |
| `--duration` | 不限时 | 仅显式设置时限时退出，秒 |
| `--feedback-timeout` | 0.5 | 连续异常或没有有效反馈的超时，秒 |
| `--service-timeout` | 1 | 控制请求响应超时，秒 |

每次按 `Δq = 限幅(kp × 力误差, ±max-step)` 更新上次位置目标，死区内保持，最终目标按公共关节范围限幅。预览只计算当前反馈对应的一步，不累积虚拟运动。目标力无法达到时，位置目标可能逐步到达限位；参数尚未经真机整定。

缺少配置力通道或非有限数值的帧静默丢弃，恢复有效反馈前暂停更新，持续超过反馈超时则退出。任一已收到的受控通道有有限超力值时立即锁存故障，即使同帧其他通道无效也不忽略超力。

默认持续维持抓握；交互式终端中按 `q`（无需回车）或 Ctrl+C 退出。显式设置 `--duration` 时，到期也会退出。

## 公共限位、过滤与复位

控制从启动时采集的有效位置 `initial_rad` 开始。所有请求（含复位）在发送前校验六关节目标；使用 [hand_common.py](hand_common.py) 的 `LIMITS`，该测试限位可比硬件范围更保守。

结构错误、缺少关节、非有限值或越界的关节整帧静默丢弃，不刷新有效位置和时间。恢复有效帧前不发送正常控制请求。默认连续异常或无有效关节反馈 0.5 秒后退出；启动无有效反馈时最多等待 5 秒。反馈新鲜度按本机接收时间判断，不能证明机器人采样时间新鲜。

右手退出复位目标固定为 `hand_common.py` 中的 `RIGHT_RESET_RAD`，不随每次启动位置变化；显式选择左手时，使用该次启动位置。启动日志中的 `reset_target_rad` 显示实际复位参考，配置数值以代码为准。

按 `q`、Ctrl+C、收到 SIGTERM、限时结束或程序报错，均进入退出处理：

1. 预览只打印复位目标，不调用服务。
2. 实际执行模式先等待旧请求结束，再发送复位参考；没有有效初始位置或旧请求持续未响应时不发复位。
3. 复位响应成功后，要求新的有效反馈确认所有关节误差不超过 `0.03 rad`，才打印 `Reset verified`。旧请求、复位响应、位置确认分别最多等待 3 秒。

服务不可用、拒绝复位或无法确认到位时输出 `RESET FAILED`。复位是额外的位置动作，不等同于张手；断网、断电、强制终止或再次中断清理时无法保证完成。
